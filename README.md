# PetFamily

PetFamily is a web application built with Django that helps people find pets from shelters and breeders.  
Users can browse animals, view detailed information, and send adoption requests.

## Features

- User authentication
- Shelters and breeders profiles
- Pet listing page
- Pet detail page
- Adoption request system
- User profile page
- Responsive UI
- Django admin panel

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Tailwind CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/PaniShews/PetFamily.git
```
